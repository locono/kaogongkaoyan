# 考公考研 · kaogongkaoyan.com

一个面向考公、考研人群的**纯静态资源导航站**，把课程目录、笔记网盘群、更新日志和公众号入口集中在一页里，扫码即关注、点击即跳转。

## 项目特点

- **单文件结构**：整站只有一个 `index.html`，样式与脚本全部内联，二维码图片以 base64 内嵌，零外部依赖，打开即用。
- **纯静态部署**：无需构建、无需后端，直接把 `index.html` 放到 Cloudflare Pages 即可上线。
- **响应式设计**：手机、平板、宽屏 PC 自动适配缩放；宽屏下页尾两个公众号卡片并排为一行，窄屏自动堆叠。
- **现代化视觉**：极光渐变背景、玻璃拟态卡片、渐变大标题与域名标识。

| 页尾 | 公众号「花生考公」「考研网盘」二维码（微信扫码关注）、联系 QQ（点击复制并提示「QQ已复制」）、站点网址 kaogongkaoyan.com |

## 交互细节

- 点击 QQ 号码：自动复制到剪贴板，并弹出「QQ已复制」提示（兼容非 HTTPS 环境的降级复制方案）。
- 返回顶部：右下角悬浮按钮，页面下滑后出现。
- 导航日期：由 JavaScript 自动读取访客本地日期，显示「年月日 + 星期」。

## 部署方式

将 `index.html` 上传至 Cloudflare Pages（构建命令留空，输出目录填 `index.html` 所在目录）即可完成部署，无需任何额外配置。
